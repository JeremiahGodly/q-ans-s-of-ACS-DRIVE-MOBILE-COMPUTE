Mobile Computing: CSMA/CA RTS/CTS & Hidden Terminal

Mobile Module 3: MAC
Medium Status: Idle
KTU Exam Core Concept: The Hidden Terminal Problem occurs when Node A and Node C cannot hear each other, causing collisions at the Access Point (AP). IEEE 802.11 solves this using virtual carrier sensing: Node A sends Request-to-Send (RTS) $\to$ AP replies with Clear-to-Send (CTS) containing the duration field $\to$ Node C overhears CTS and freezes its transmission via Network Allocation Vector (NAV).
